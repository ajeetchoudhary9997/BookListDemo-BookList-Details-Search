# 📚 Book Demo App

A modern Android demo application built with **Jetpack Compose** following **Clean Architecture** and **MVI**.

## Features
- Book List screen
- Book Details screen
- Search screen with **debounced search** using Kotlin Flow
- Navigation using **androidx.navigation:navigation-compose**

## Tech Stack
- Kotlin
- Jetpack Compose (Material 3)
- Clean Architecture
- MVI
- Koin (Dependency Injection)
- Kotlin Coroutines & Flow
- Navigation Compose

## Purpose
This project serves as a reference implementation for building scalable Android apps using modern Android development practices.
